# Динамика спроса на различные товарные категории в зависимости от сезонности

Прогнозно-аналитическая система для предметной области «Электронная коммерция».
Проектная работа по дисциплине «Прогнозно-аналитические системы», профиль «Управление данными».
Тема согласована с преподавателем.

## Описание проекта

Система исследует динамику недельного спроса по товарным категориям интернет-магазина
и моделирует её зависимость от сезонности:

- **годовой сезонности** — месячные профили категорий (пики ноября–декабря, провалы
  сентября–октября, январский пик канцтоваров);
- **недельной сезонности** — эффект дня недели (провал выходных);
- **календарной сезонности** — праздники, Black Friday, школьный сезон;
- **дополнительных сезонных драйверов** — зарплатные циклы и осадки.

Система реализует полный цикл работы с данными: автоматизированный сбор из нескольких
разнородных источников, хранение исходных и обработанных данных, контроль качества,
преобразование и объединение, построение прогноза и представление результатов
на дашбордах.

## Предметная область

Электронная коммерция (интернет-маркетплейс). Историческое ядро — публичный датасет
**Olist Brazilian E-Commerce** (Kaggle): ~99 тыс. заказов, ~112 тыс. позиций заказов,
71 категория товаров, период 2016-09 — 2018-10. Рабочий год для анализа сезонности —
2017-09 — 2018-08 (плотный период данных). Реальные коммерческие данные российского
e-commerce публично недоступны, поэтому ядро построено на открытом транзакционном
датасете с категориями и временными метками, а внешние факторы берутся из живых API.

## Прогнозируемый показатель

Показатель, выражающий динамику спроса, — **недельный объём спроса по товарной
категории**: количество проданных единиц товара за ISO-неделю (сумма позиций заказов).

- гранулярность: неделя × категория;
- горизонт прогноза: 4 недели;
- разрезы дашборда: категория (топ-10), неделя, праздничные и промо-периоды.

## Практическая задача и пользователи

Планирование закупок, складских запасов и промо-активностей: снижение дефицита и
неликвидов, выбор окон для промо. Пользователи: категорийные менеджеры, аналитики
отдела закупок, маркетинговые аналитики, руководитель направления e-commerce.

## Источники данных

| Источник | Тип | Формат | Обновление | Режим загрузки |
|---|---|---|---|---|
| Olist Brazilian E-Commerce (Kaggle) | файлы | CSV | статичное историческое ядро | инкрементально по watermark `order_purchase_timestamp` |
| Open-Meteo Archive API (Сан-Паулу, Рио-де-Жанейро) | REST API | JSON | ежедневно | инкрементально по дате |
| Nager.Date API (праздники Бразилии) | REST API | JSON | ежегодно | полное обновление по годам |
| Коммерческие даты (Black Friday, Dia das Mães, Dia dos Pais) | внутренний справочник | код/конфиг | вручную | upsert |

Разнородность источников: транзакционные файлы, физические данные (погода),
календарные данные (праздники), ручной справочник событий.

## Архитектура

```
Источники → extract (retry, timeout, DQ-проверки)
          → слой raw (SQLite, данные «как пришли», метки загрузки)
          → очистка, дедупликация, объединение, справочники
          → слой mart (недельная витрина спроса + признаки сезонности)
          → прогнозные модели (базовая сезонная + градиентный бустинг)
          → дашборды: предметный и операционный
```

Слои хранения зафиксированы префиксами таблиц SQLite: `raw_*` — исходные данные,
`mart_*` — витрины. Служебные таблицы: `load_log` (журнал загрузок), `load_state`
(watermark'и инкрементальности), `dq_results` (результаты проверок качества),
`rejected_rows` (отбракованные записи с payload).


## Ключевые выявленные зависимости (EDA)

Подробности и графики — `notebooks/01_eda_olist.ipynb`:

- **Black Friday — главный пик спроса** (2–4× к обычной неделе), сильнее рождественского;
- **отложенный спрос**: разгон спроса за 1–2 недели до BF (1.4–1.6×) и пик 2.3× в день BF;
- **weekend-провал**: суббота 0.76× против понедельника 1.14× — вопреки интуиции
  о «шопинге в выходные»;
- **зарплатный цикл**: пик через 2–4 дня после выплаты (1.19×), провал в середине
  межзарплатного периода (0.81×);
- **январский пик канцтоваров** (2.6×) — школьный сезон Бразилии начинается в феврале;
- **январский спад игрушек и консолей** (0.76–0.85×) — спрос уже удовлетворён праздником
  праздничными покупками;
- **«летняя подготовка» южного полушария**: пик садового инвентаря (3.8×) и автотоваров
  (1.6×) в ноябре — перед бразильским летом;
- **осадки**: дождливая неделя снижает спрос во всех 14 проверенных категориях
  (r = −0.11…−0.25 после снятия годовой сезонности);
- **отрицательный результат**: корреляция спроса с температурой (r ≈ −0.3) опровергнута
  контрольным экспериментом — эффект объяснялся годовой сезонностью; температурные
  признаки в модель не включены.
