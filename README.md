# Прогнозирование спроса на товарные позиции интернет-магазина

## Описание проекта

Прогнозно-аналитическая система для анализа и прогнозирования спроса на товары интернет-магазина с учетом погодных условий.

Проект реализует сбор, обработку и объединение данных о продажах и погоде, построение прогнозной модели и визуализацию результатов.

## Предметная область

**Электронная коммерция (E-commerce).**

## Прогнозируемый показатель

**Спрос на товарные позиции.**

Спрос определяется через количество проданных единиц товара (`order_quantity`). Прогноз строится на горизонте 7–14 дней с учетом истории продаж, календарных признаков и погодных условий.

## Источники данных

1. **E-Commerce Dataset (`Ecommerce_data.csv`)** — данные о заказах, товарах, клиентах, датах, количестве продаж и местоположении покупателей.

2. **Open-Meteo API** — погодные данные по дате и местоположению: температура, осадки, влажность, скорость ветра и другие показатели.

Источники объединяются по дате и географическому признаку.

```text
config/           # конфигурационные файлы

```

## Запуск

1. Клонировать репозиторий:

```bash
git clone <url>
```

2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Запустить обработку данных и прогнозирование.

## Результат

Система формирует прогноз спроса на товарные позиции и позволяет анализировать динамику продаж и связь спроса с погодными условиями.
