# Прогноз спроса на товарные позиции маркетплейса

## Описание проекта
Прогнозно-аналитическая система для оценки спроса на товары российских поставщиков маркетплейса Ozon. Система использует прокси-метрики (остатки, отзывы, цены) для прогнозирования спроса на горизонте 7-14 дней.

## Предметная область
Электронная коммерция (Ozon Seller API).

## Прогнозируемый показатель
Спрос на товарные позиции (оценивается через динамику складских остатков, прирост отзывов и ценовую эластичность).

## Источники данных
1. **Ozon Seller API (v2.1)** — бизнес-данные: товары, остатки, цены, рейтинги (JSON/REST).
2. **Внешние факторы** — календарь праздников РФ (библиотека `holidays`) и погодные условия (OpenWeatherMap API) для учета сезонности.

## Структура проекта
- `data/raw/` — сырые данные (не хранятся в Git)
- `data/cleaned/` — очищенные данные
- `data/mart/` — витрина данных для анализа
- `src/` — исходный код ETL-конвейера
- `config/` — конфигурационные файлы (.env.example)

## Как запустить
1. Клонируйте репозиторий: `git clone <url>`
2. Создайте файл `.env` на основе `.env.example` и добавьте API-ключи.
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите сбор данных: `python src/collector.py`
