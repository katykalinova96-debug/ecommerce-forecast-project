# Прогноз спроса на товарные позиции маркетплейса

## Паспорт проекта

* **Предметная область:** Электронная коммерция (E-commerce). Анализ транзакционной активности маркетплейса в разрезе категорий товаров и регионов с учётом внешних факторных условий (погода, календарная сезонность).
* **Прогнозируемый показатель:** Дневной спрос по товарным категориям (`category_name`):
  * Суммарная выручка (`total_sales`)
  * Количество заказов (`order_count`)
  * Средний чек (`avg_order_value`)
  *(Горизонт прогнозирования: 7–14 дней)*
* **Практическая задача:** Оптимизация управления товарными запасами на складах и предотвращение дефицита (out-of-stock) или перенасыщения складов в регионах с высокой зависимостью спроса от погоды и сезонности.
* **Целевой пользователь:** Менеджеры по закупкам и логистике (управление запасами), а также Data-аналитики e-commerce компании.
* **Источники данных:**
  1. *Транзакционный лог (CSV):* Исторический датасет `Ecommerce_data.csv` (заказы, товары, даты, города клиентов, суммы).
  2. *Внешний метеорологический фактор (Open-Meteo REST API):* Автоматически загружаемые JSON-данные по температуре и осадкам в городах доставки.
* **Архитектура репозитория:** Структурированный проект с модульным Python-кодом (`src/`), трёхуровневым хранением (`data/raw/`, `data/cleaned/`), журналами проверок качества/загрузок (`logs/`), автоматическим запуском (`main.py`) и документацией.
