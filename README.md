# Прогноз спроса на товарные позиции маркетплейса

## Описание проекта
Прогнозно-аналитическая система для оценки и прогнозирования спроса в электронной коммерции. Система реализует полный цикл работы с данными: от автоматизированного сбора разнородных источников до формирования витрины данных для построения прогнозных моделей временных рядов. Проект разработан в рамках дисциплины «Прогнозно-аналитические системы» профиля «Управление данными».

## Предметная область
Электронная коммерция (E-commerce). Анализ транзакционных данных маркетплейсов с учетом внешних экзогенных факторов (погода, сезонность) для оптимизации управления запасами и ценообразованием.

## Прогнозируемый показатель
**Спрос на товарные категории.** 
Оценивается через агрегированные метрики: суммарная выручка (`total_sales`), количество заказов (`order_count`) и средний чек. Прогнозирование осуществляется на горизонте 7–14 дней с учетом влияния погодных условий и календарной сезонности.

## Источники данных (Разнородные)
Для обеспечения полноты анализа используются два источника различного типа:
1.  **Транзакционные данные (Kaggle):** Исторический датасет E-Commerce (`Ecommerce_data.csv`). Содержит информацию о заказах, клиентах и товарах. Используется как базовый слой хранения (Raw) для обучения моделей.
2.  **Внешние факторы (OpenWeatherMap API):** Метеорологические данные (температура, осадки, состояние погоды). Загружаются автоматически через REST API для учета влияния климатических условий на спрос. Интеграция выполняется по ключу `order_date`.

## Структура проекта
- `data/raw/` — сырые данные (исторический CSV, логи загрузок)
- `data/cleaned/` — очищенные и объединенные данные (витрина для ML)
- `src/` — исходный код ETL-конвейера и скрипты сбора
- `notebooks/` — Jupyter Notebooks для разведочного анализа (EDA)
- `config/` — конфигурационные файлы (.env.example)
